# Website project owner rules

For Zadeyo referral website work in this workspace, read `PROJECT_RULES.md` first.
These are the owner's standing instructions from 2026-11-02, including confirmed
UGC meaning and 30-day monthly terms, with the setup clarification of 2026-11-05.
They take precedence over conflicting inherited template defaults. Apply them to
every future game conversion here.

- Use Parts 1–4 in `START_HERE.md`: English commercial rewrite; images then
  competitor-researched blogs/forum answers; cleanup/URLs/links then translations;
  light theme, mobile, desktop and final SEO/crawl verification.
- For each new site, first set up the working copy in a folder named after the exact
  supplied domain, e.g. `valoranthacks.com/`. Preserve the reusable master and any
  existing site; copy these rule files into the new project's root.
- Start each conversion by auditing the complete template, assets and built output.
- Obtain the target game, exact domain, primary keyword, referral URLs, authorized
  game images and relevant competitor URLs before dependent implementation.
- HWID Spoofer: USD $50 monthly for 30 days; USD $150 lifetime.
- All other products: USD $35 monthly for 30 days; USD $150 lifetime.
- English is primary; retain English, Spanish, German and French.
- Publish one `/sitemap.xml` with all four locales, page priorities and reciprocal
  language alternates; show all four alternates in indexable page source too.
- Use Zadeyo's recorded dark/purple/white visual palette; never use its copy or
  images as factual/content references.
- Preserve the template layout and section order throughout. Rewrite full copy and
  article bodies; config/name changes or proposed titles alone never complete a site.
- Label generated forum answers as publisher/editorial content; extend the baseline
  content contract in a conversion, without fabricating users, reviews or engagement.
- Product lineup and all writing must fit the particular game and verified facts.
  Preserve approved utility images; replace previous-game images and blog artwork.
- Never carry previous-game branding, copy, SEO, links or redirects into a fresh
  site. Scan source, filenames, assets and generated output before completion.
- Ask about essential missing business facts; do not invent functionality,
  compatibility, anti-cheat/error meanings, reviews, availability or guarantees.
- Use original, researched articles and contextual locale-correct internal links.
- Do not promise rankings or mistake sitemap priorities for a Google ranking signal.
- Target actual 100/100 Lighthouse SEO and applicable Seobility checks; use Screaming
  Frog crawl evidence. Report unavailable tools honestly; never claim perfect SEO.
- Finish the required source/output/runtime and desktop/mobile checks; fix observed
  failures, report untested items, update `PROJECT_STATUS.md` and provide localhost.
- Work locally unless publishing/pushing/indexing has actually been requested.

The reusable master checkout is `zadeyo-template/`; converted sites use their exact
domain as the folder name. Each checkout's `AGENTS.md` and documentation explain
implementation ownership. The original five conversion/QA skills named there
were not found in this environment on 2026-11-02; use available relevant skills
and existing checked scripts instead of claiming those missing skills were used.

Keep audit notes and private provenance outside deployable content. Future chats
outside this workspace need a copy/link to `PROJECT_RULES.md`; do not claim
account-wide memory or model training from this chat.
