# Dependency review — Part 4.1

2026-10-30. `npm audit --json` initially reported 11 affected packages covering 30 advisory records (1 critical, 9 high, 1 moderate package-level severity). After targeted updates, the full audit, including development dependencies and the new QA tools, reports **zero vulnerabilities**. Audit evidence is in ignored `.astro/part41-audit-before.json` / `part41-audit-after.json`; refresh with `npm audit --json` because advisory coverage changes.

The deployed entry is `workers/site.js`, with repository-local routing helpers and the native `ASSETS` binding. It does not import Astro, Sharp, Vite or the packages below. Astro generates static HTML/JS/CSS locally or in the deployment build. No SSR adapter, runtime image endpoint, uploaded-content backend, request-derived view-transition values, JSX/MDX integration or user-authored server content was found. Public visitors therefore cannot reach the affected Node build/dev APIs in this deployment. This is an applicability assessment of the current source, not a universal statement that the packages were safe. Build operators could still expose themselves to malicious image/source/config inputs; all findings were patched rather than waived.

| Package | Before → patched lock | Investigated vectors / current applicability |
| --- | --- | --- |
| Astro | 7.1.1 → 7.3.3 | Four advisories: AVIF native-library RCE, base-path stripping boundary, JSX/MDX script/style escaping, transition CSS injection. Image processing is build-time with repository assets; base routing concerns dev/server behavior; no JSX/MDX or untrusted transition values in current static source. Patched Astro also requires the newer Sharp series. |
| Sharp | 0.34.5 → 0.35.5 | Three advisories covering libvips, libheif/AVIF and librsvg. Build/image-generation tooling only, using local supplied media. This is the important build-time untrusted-media surface; updated native libraries rather than accepting it. |
| devalue | 5.8.1 → 5.9.4 | Eight advisories: malformed input DoS, shared-memory serialization, sparse-array CPU/allocation amplification, repeated-string expansion, async rejection, null-prototype key coercion, custom ArrayBuffer revivers. Astro serialization uses trusted static data; no request-facing deserialization/reviver endpoint. |
| js-yaml | 4.3.0 → 4.3.2 | Two merge/omap CPU-amplification advisories. Configuration/parser tooling; no public YAML input or YAML-backed route content found. |
| nanoid | 3.3.16 → 3.3.20 | Zero-sized custom-generator infinite loop. Transitive build tooling; no application call to a visitor-controlled custom generator. |
| postcss | 8.5.19 → 8.5.32 | Attacker-controlled sourceMappingURL could read map files when `from` is absent. Build-time CSS processing; current sources/configuration are repository controlled. |
| smol-toml | 1.7.0 → 1.9.1 | Two malformed-document/quadratic-key parsing DoS advisories. Local config/build parsing; visitors cannot supply TOML. |
| source-map-js | 1.2.1 → 1.2.2 | Indexed-map section-offset event-loop DoS. Transitive CSS/build tooling processing repository build inputs. |
| svgo | 4.0.2 → 4.1.0 | Two sanitizer bypasses involving foreignObject links, namespaces and control characters. Build-time SVG optimization; not a public uploaded-SVG sanitization service. Existing artwork remains unchanged. |
| Vite | 8.1.5 → 8.3.5 | Five advisories: three Windows editor-command/existence-check issues, cross-origin dev middleware execution, filesystem allow-list bypass. Development server/tooling; production uses the custom Worker or Node static server, not Vite dev middleware. Do not expose a development server as production. |
| Zod | 4.4.3 → 4.6.7 | Oversized constrained-collection memory exhaustion. Configuration/build tooling; no public request-validation endpoint in this static project. |

Selected Astro 7.3.3 as the smallest release outside all reported Astro ranges, retaining its declared Node >=22.12.0 support. The latest Astro at review time required a higher Node minimum and was unnecessary. Astro remains on major 7. Sharp 0.35.5 leaves the former `^0.34.3` range because the required native-library fixes are in 0.35; it is an intentional security update, not an automatic `audit fix --force`. Direct Astro/Sharp versions and QA tools are pinned, and the lockfile records the patched transitive versions. No overrides or vulnerability exceptions were added.

Added development-only `playwright-core@1.64.1` (uses separately installed Chrome) and `wrangler@4.156.0` (local workerd/static-asset testing, also pins the existing deployment CLI). These do not add application-side scripts or runtime libraries to public pages. Wrangler telemetry is disabled by the test harness, `--local` disables remote bindings, and automatic skill installation is not enabled. No new skills were installed.
